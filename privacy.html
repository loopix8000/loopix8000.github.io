1. 처리하는 정보와 목적

처리 항목목적
원고·메모·작품 정보·표지·수정 이력문서 저장, 편집, 검색, 복원 및 동기화
앱 설정, 저장소 주소·계정·인증 정보, 문서·기기 식별자설정 유지, 저장소 연결 및 동기화 상태 관리
Google 계정 이메일·Drive 계정 식별자·OAuth 토큰Google Drive 연결 시 계정 확인 및 인증 유지
앱에 접근이 허용된 Drive 파일의 내용·이름·ID·소유 정보Google Drive 연결 시 문서 동기화

정보는 기기에 저장하며, 외부 저장소를 연결한 경우 동기화에 필요한 정보를 해당 저장소로 전송합니다. 개발자가 원고나 이용 기록을 별도 서버로 자동 수집하지 않습니다.

2. Google 사용자 데이터

Google Drive 연동을 지원하는 버전에서 사용자가 계정을 연결하고 동의한 경우에만 Google 사용자 데이터에 접근합니다. 요청 권한은 https://www.googleapis.com/auth/drive.file이며, 앱이 생성하거나 사용자가 접근을 허용한 파일을 대상으로 합니다. Google 계정 비밀번호는 받거나 저장하지 않습니다.

Google 사용자 데이터는 계정 확인과 문서 동기화에만 사용하며, 판매·광고·프로파일링·AI 모델 학습에 사용하지 않습니다. 데이터 이용 및 전송은 Google API Services User Data Policy의 제한적 사용(Limited Use) 요건을 준수합니다.

3. 보관 및 보호

원고·이력·설정은 사용자의 기기에, 동기화 사본은 사용자가 선택한 저장소에 보관합니다. 수정 이력은 앱 동기화 대상에 포함하지 않습니다.

Google 통신에는 HTTPS를 사용하며, Windows에서 저장소 비밀번호와 Google 갱신 토큰은 Windows 계정 기반 암호화로 보관합니다. 원고 파일 자체는 암호화하지 않습니다.

4. 보관 기간 및 삭제

  • 원고와 설정은 사용자가 삭제할 때까지 보관합니다.
  • 수정 이력은 하루 한 번 최근 100개·30일을 기준으로 정리하되 문서당 최소 10개를 보존합니다. 문서 삭제 시에도 이력은 남을 수 있습니다.
  • 연결을 제거하면 기기에 저장된 해당 연결 정보를 삭제합니다. Google 접근 권한은 Google 계정의 연결 관리에서 별도로 철회할 수 있습니다.
  • 연결 해제나 앱 삭제만으로 원고·이력·백업·원격 사본이 모두 삭제되지는 않습니다. 해당 파일은 각 기기와 저장소에서 직접 삭제할 수 있습니다.

5. 외부 서비스

동기화를 연결하면 문서가 사용자가 선택한 저장소로 전송됩니다. MCP/API를 외부 도구에 연결하면 해당 도구가 문서에 접근할 수 있습니다. 각 서비스에서의 데이터 처리에는 해당 서비스의 개인정보처리방침이 적용됩니다.

홈페이지 호스팅과 업데이트 배포를 제공하는 GitHub는 접속 과정에서 IP 주소 등 통신 정보를 처리할 수 있습니다. GitHub 개인정보처리방침 · Google 개인정보처리방침
